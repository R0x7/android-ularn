# Wild Edition features

One short page per feature: what it is, how to find or use it in the game,
and the setting that turns it off. The design brief for all of them is
[`../WILD_EDITION_PLAN.md`](../WILD_EDITION_PLAN.md). Everything is on by
default for new games; Settings → *Wild features* has one checkbox per
feature (a saved game keeps the set it was started with).

| Feature | Page | In one line |
|---|---|---|
| Dungeon Radio | [radio.md](radio.md) | Procedural chiptune soundtrack and SFX; cassette tapes unlock bonus tracks |
| Monster Trading Cards | [cards.md](cards.md) | Kills drop collectible cards (holo!) into a permanent album |
| Vending Machines | [vending.md](vending.md) | Buy or kick machines for junk food, a rubber duck of identification, and a loot-eating Roomba |
| Hats | [hats.md](hats.md) | Five hats with effects, drawn on your sprite |
| LarnCoin | [coin.md](coin.md) | A volatile cryptocurrency at the bank, an ATM, and a Tax Auditor |
| The Glitch Realm | [glitch.md](glitch.md) | A scroll of segfault corrupts reality: scrambled names, items and a null pointer monster |
| Fishing | [fishing.md](fishing.md) | Fish at fountains for fish, boots, bottles, rings... or the Fountain Kraken |
| Pets | [pets.md](pets.md) | A mysterious egg hatches into a companion that follows and fights |
| Level-up perks | [perks.md](perks.md) | Choose one of three roguelite perks on every level-up |
| Atmosphere | [atmosphere.md](atmosphere.md) | Weather and day/night on the surface (lemming migrations!) and a Polaroid photo mode |
